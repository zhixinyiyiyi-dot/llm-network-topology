Packet Tracer 人工部署指南
生成配置尚未执行；本程序不打开 PT、不连接任何设备。
仅在本地仿真环境使用。先另存一个副本再部署。
下列配置面向新建或已确认没有冲突配置的设备，默认不会清除旧配置；指定 --migrate-from-rip 时会移除 RIP 路由进程。
若在已有同名同接口拓扑上使用，应先审查现有配置。

一、设备、接口及接线
PC0 FastEthernet0 <-> R0 GigabitEthernet0/0
R0 GigabitEthernet0/1 <-> R1 GigabitEthernet0/0
R0 GigabitEthernet0/2 <-> R2 GigabitEthernet0/0
R1 GigabitEthernet0/1 <-> R3 GigabitEthernet0/0
R2 GigabitEthernet0/1 <-> R4 GigabitEthernet0/0
R3 GigabitEthernet0/1 <-> Switch0 FastEthernet0/1
R4 GigabitEthernet0/1 <-> Switch0 FastEthernet0/2
Server0 FastEthernet0 <-> Switch0 FastEthernet0/3

路由器需具备 YAML 中列出的串行接口；按现有 UC-01 拓扑选型与接线。

二、PC 的 Desktop > IP Configuration（Static）
PC0 FastEthernet0：IP 10.1.0.10；掩码 255.255.0.0；网关 10.1.0.254
Server0 FastEthernet0：IP 203.0.113.100；掩码 255.255.255.0；网关 203.0.113.1

三、部署与验证
人工审查所有 .cfg 后，再自行决定是否粘贴到对应 PT 路由器的 CLI。
在设备 > 提示符下粘贴；若处于配置模式，先输入 end。
出现密码提示应停下来检查，不要继续盲目粘贴。
先配置路由器，再设置 PC 地址。等待接口与路由收敛后验证。
在三台路由器的特权模式执行 show ip interface brief、show ip protocols、show ip route。
在对应 PC 的 Command Prompt 执行以下测试：
PC0：ping 203.0.113.100
Server0：ping 10.1.0.10
PC0 可对checks中对应目标执行tracert，保存实际路径结果。
以上是人工验证步骤，不是自动验收。
确认结果后，在路由器 # 提示符下执行 copy running-config startup-config，按回车接受文件名。
最后保存 .pkt 文件。

范围：IPv4/RIPv2/OSPF 配置模板；支持单地址NAPT、静态路由；支持VLAN access/trunk、单臂子接口与SVI；支持扩展IPv4 ACL及UC07指定策略；并非状态防火墙。
内置白名单和危险词检查仅审查本程序生成的命令，不是完整 Cisco CLI 语法/语义分析器。
本程序没有自动部署功能，也未实现自动部署前 CONFIRM 门。
